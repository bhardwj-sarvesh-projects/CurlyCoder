Show the CURLYCODER quick reference. One shot, change nothing: do not switch mode, write flag files, or persist anything. Levels: /CURLYCODER lite (build what's asked, name the lazier alternative in one line), /CURLYCODER (full, the default ladder: YAGNI then stdlib then native then one line then minimum), /CURLYCODER ultra (deletion before addition, challenges the requirement before building). Commands: /CURLYCODER-review (over-engineering review of the current changes), /CURLYCODER-audit (whole-repo over-engineering audit), /CURLYCODER-debt (harvest CURLYCODER: comments into a tracked ledger), /CURLYCODER-gain (measured-impact scoreboard from the benchmark), /CURLYCODER-help (this card). Deactivate with 'stop CURLYCODER', 'normal mode', or /CURLYCODER off; resume anytime with /CURLYCODER. Default mode is full; change it with the CURLYCODER_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/CURLYCODER/config.json (Windows: %APPDATA%\CURLYCODER\config.json) with {"defaultMode": "lite"}. Resolution order: env var, then config file, then full.
